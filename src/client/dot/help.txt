.spun [OPTIONS] COMMAND

SPUN package manager

commands:
 find TEXT [PAGE]
 info APPID [PAGE]
 get APPID
 update

options:
 -s xxxx Alternative Server
 -p xxxx Alternative Port
 -q      Quiet
 -v      Version

Put TEXT with spaces in quotes:
 .spun find "two words" 2
